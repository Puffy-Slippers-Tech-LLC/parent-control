# Let a parent approve time for later

Acceptance: host

Prerequisite is 006. Follow [deferred saving](../Save-For-Later-Design.md#saving-approved-minutes),
[caller binding](../Save-For-Later-Design.md#caller-and-session-binding),
and [Polkit effect admission](../SystemDesign/Broker.md#request-lifetime-and-effect-admission).

Implement the shared deferred approval path and its trusted prompt rendering
on both surfaces. Bind selected parent, caller session, target, fixed duration,
app choice, and request mode through effect admission. Refuse Rest of the day
before authentication. After admission, durably add the approved seconds and
choice with no grant or policy write. Then invoke the shared pause when a
fixed grant runs, returning the committed new balance and the pause failure
when only the save succeeds. Respect the existing immediate approval behavior
and name the two modes in the trusted prompt. Translate changed product copy
in all supported languages under the [localization contract](../SystemDesign/Localization.md#native-authentication-fallback).

Run focused authorization and transaction checks for both surfaces, selected
parent and mode, cancellation/denial/caller loss or a stale revision before
admission, merge limits, independent saved choice, and partial success. Check
the 18 + 20 example at B and that the save adds no daily time. Run the queued
package check and release owned test resources.
