# Decide which faults fail a test

Acceptance: host

[Master plan](../Error_Reporting.md) · [Task queue](Task_Queue.md)

Use the qualified contract from task 001 to implement one evaluator in shared
test support. Decode and validate the minimal structured record and accept
evidence only for the owned guest, boot and case interval. Keep the transport
independent of the evaluator. Match an allowance on the emitting component and
stable category within its explicit action window. Use the guest-side occurrence
ordering from task 001 to place late records. Ignore exception type, message,
stack, source location and occurrence count for matching. The product assertions
in the case still establish the deliberate fault and recovery. Close the
allowance before the recovery checks begin.

Use the existing [runner verdict and repair contracts](../../../tests/README.md#scripted-repair-loop).
A valid unexpected event produces the ordinary failed case with its identity,
category and bounded diagnostic context. A verified fault or independent case
failure retains repair eligibility if collection also fails. A read failure,
invalid required evidence or a known observation gap on an otherwise passing
case produces a visible infrastructure blocker without starting a repair
session. Carry that disposition through case adapters, the VM queue, and the
repair launcher's command-failure fallback. After any bounded read recovery,
a persistent blocker ends the invocation after owned cleanup and leaves the
case pending for explicit resume.

Use the lowest effective host checks under the
[test scope mandate](../../Mandates/Test-Scope-Mandate.md). Exercise the shared
verdict with a clean span, stale evidence, an allowed category with varied
details and zero or many events, and an unrelated fault inside the window.
Compare a fault that occurs just before the allowance closes and arrives late
with the same fault occurring after it closes. Check incomplete evidence with
and without an independent failure.
Use the existing host repair seam to check that repair dispatch reaches its
normal session-start boundary for a real failed case and ends the invocation
without an agent or indefinite retries for a persistent observation-only
blocker. Keep scratch and diagnostics on the ordinary test storage route and
finish owned cleanup.
