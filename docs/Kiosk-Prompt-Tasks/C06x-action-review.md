automatic launches. In the existing confinement design owner, record each
child's actual access, deliberate action, prohibited result, smallest enforcement

Return full-desktop-enabling steps to the desktop owner; reuse shared barriers
without duplicate implementation. Keep standalone terminal/TTY/SSH in C06a's map
and consumed file/environment/settings inputs in C06i. Unknown host content or an
arbitrary-kiosk-code premise supplies no justification for refusal.

Name affected source functions, retained case identities, existing automation
bindings and exact missing operations for C06's review and C08a's implementation.
Classify already effective and excluded routes explicitly. This task performs no
product changes or live qualification; check links/metadata and leave no temporary
resources. Missing evidence of child access remains a design gap, not a mandate
for speculative hardening.
