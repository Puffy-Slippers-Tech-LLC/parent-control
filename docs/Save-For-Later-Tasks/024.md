Acceptance: installed
Targets: onpc-Ubuntu26.04-101, onpc-Fedora44-201, onpc-Fedora45-301

Prerequisite is 021. Own the daily-time variant of
[Scenario 3](../Save-For-Later-Design.md#scenario-3-pause-save-and-use-time-from-the-child-overlay).
Follow the [app-policy rules](../Save-For-Later-Design.md#app-policy-revocation-and-other-lifecycle-operations)
and [E2E implementation route](../../tests/e2e/README.md#verify-edits).

Start in a signed-in child session with 30 minutes of daily time, no running
grant and no saved time, set up through public controls. Save 15 minutes from
the overlay without locking. Before Use saved time, change one of the approved
soft apps to hard blocked in Parent and leave one soft. Redeem while daily
time is usable and require the immediate countdown increase and overlay
closure. Check the two apps through existing normal launch routes to verify
the stored choice and current policy. With the redeemed fixed grant running,
defer one additional minute and confirm the lock. Require daily-only access on
password unlock and verify the saved balance after the transfer boundary.
Submit one immediate approval in the overlay and confirm the saved balance
stays saved. Keep each observation within the same installed attempt.

registration from 021 and record its coverage ID in this brief before running.
List and run that exact case on every declared target after composition
preflight and affected host checks. Use separate host/engineering checks for
