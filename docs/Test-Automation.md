# Test automation execution entry point

This is the stable entry point for the test-automation execution plan.

For an explicit plan review or revision, read the requested unfinished tasks
and edit the plan directly. The model-selection pause below applies to task
implementation, not documentation maintenance. Completed task text and records
remain unchanged during such a review.

Before executing a task:

1. Read `AGENTS.md`.
2. Read this file.
3. Read [the master plan](TestAutomation/Test-Automation.md).
4. Locate the first unchecked task in the master plan and follow its document
   link. Read the shared introduction and that task's section only; a document
   may contain several separately executable lettered tasks. Do not read other
   task documents or later sections.
5. Report that task's recommended model and reasoning effort, then stop. Make
   changes only after the user switches to that model and effort and asks for
   execution.

When executing a task, execute exactly that one task, run only its stated
verification plus the required common checks, update both of its checkboxes in
the master plan, append its completion record there, and stop. Never redo checked
tasks or execute a later task in the same session.

The master plan contains the overall summary, sequencing rules, shared
verification requirements, traceability rules, stable command interfaces, task
index, and completion records. The task documents contain the detailed work and
verification for their individual task or lettered task sections.

Task documents: [master plan](TestAutomation/Test-Automation.md).
