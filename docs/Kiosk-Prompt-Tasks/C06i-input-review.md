## Session boundary and deliverable

Extract consumed-input discovery from C06. Trace actual fixed entrypoints,
environment/search selection and startup/settings consumers. Record only inputs
the child can really influence from a reachable account/action; distinguish that
access from root-planted engineering fixtures and ordinary readable files.

In the existing design owner, give each finite route its source functions,
actual child access, deliberate action, prohibited result, minimum enforcement
owner, negative, working trusted-code/lazy-loading positive and restoration.
Preserve useful ACL/group examples only where they establish real child access.
Return desktop-enabling steps to the desktop owner. No private Python/GI/native
loader, global roster, continuous audit or custom NSS/ACL framework is in scope.

Identify existing test bindings, stable case IDs and missing operations for
C06's independent review and C08's implementation. Classify already effective
and excluded routes with reasons. No product edits, VM setup or installed claims;
check links/metadata and preserve original evidence.
