# Verify who can control the timer and capture time at lock

Acceptance: host

Prerequisite is 001. Use the [caller and session rules](../Save-For-Later-Design.md#caller-and-session-binding),
[usage source rules](../Save-For-Later-Design.md#sources-of-d), and
[broker trust boundary](../SystemDesign/Broker.md#accounts-and-roles).

Implement caller/session validation and the lock-before-capture adapter and
helpers for use by the new transitions. Reuse process/Display resolution, bind
the same local session at effect admission, and distinguish the recheck after
the broker's own lock. Under kiosk rules, refuse an active unlocked target
desktop and lock switched-away unlocked local graphical sessions. Observe
LockedHint and each required completed usage record within the specified bound.
The caller can lower D only for operations that add it to a running duration.
Keep existing immediate-request behavior intact.

Use broker and adapter tests for kiosk user service and Shell overlay
resolution, wrong user and target, administrator, remote/closing/inactive/
locked/sessionless callers, ownership changes, timeout or missing usage,
an already locked or non-graphical session, and native-deadline spoofing.
Check affected usage-identity regressions. Run the queued package check and
release owned test resources. Treat the recorded platform qualification as the
baseline for later installed checks.
