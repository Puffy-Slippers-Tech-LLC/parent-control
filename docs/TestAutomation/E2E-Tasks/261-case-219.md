## Implementation and expected results

authorization and independently observe retry. Read the explicit Stop sending
and close action and activate it once; it stops directly, without an additional
confirmation or stay response. Require report disappearance and GDM, then
restore Internet access through the same LIFE06 helper from GDM. Stopping
cancels pending retries and does not claim remote recall.
