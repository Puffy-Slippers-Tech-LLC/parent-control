# Show saved time in Parent and let parents revoke it

Acceptance: host

Prerequisite is 010. Use the [status compatibility rules](../Save-For-Later-Design.md#serialization-and-status-reads),
[Parent frontend contract](../SystemDesign/Frontends.md#parent-controls-and-shared-information),
and [revocation effects](../Save-For-Later-Design.md#app-policy-revocation-and-other-lifecycle-operations).

Use the status transport in Parent to explain usable and saved time distinctly.
Enable existing Revoke for a positive saved-only balance as well as the current
enabling conditions. Show explicit unavailable/retry behavior and refresh
after revoke or child selection without showing stale data. Preserve the
existing revoke confirmation, error route, and disabled/pending behavior.
Translate new labels and messages in all supported languages and preserve
existing public IDs.

Use focused Parent UI and client checks for daily-only, active-only, saved-only,
mixed, loading/busy/unavailable and old-broker status. Exercise saved-only
revoke, failed revoke display, and an async response for a previously selected
child. Run the queued package check and release owned UI/service fixtures.
