# Make saved time and timer actions available to the apps

Acceptance: host

Prerequisites are 004 and 009. Use the wire contract recorded by 001, the
[implementation map](../Save-For-Later-Design.md#implementation-map), and
[status read rules](../Save-For-Later-Design.md#serialization-and-status-reads).

Register the three new mutations and GetGrantStatus in both introspection
definitions, service dispatch, and the request and Parent client transport.
Bind callers and effects to the approved wire contract and the broker worker.
Keep GetGrantStatus bounded with the specified lock and record/tuple/revision
checks. Report busy, recovery pending and unavailable explicitly. The read
itself performs no writes. Old clients retain GetTimeStatus and immediate
requests byte-for-byte at the protocol boundary. Leave visible widgets and
success navigation to their own tasks.

Run private-D-Bus and focused client tests for the caller/target matrix, payload
and revision validation, cross-client races, a pending foreign approval,
recovery-queued status, a changing snapshot, saved-with-pause-error and the
older-broker fallback. Verify disabled controls and that existing status
still measures desktop access. Run the queued package check and release owned
bus/service fixtures and staging.
