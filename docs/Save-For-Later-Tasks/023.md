# Check that pausing captures all usage on every target

Acceptance: installed
Targets: onpc-Ubuntu26.04-101, onpc-Fedora44-201, onpc-Fedora45-301

Prerequisite is 010. Use the [lock before capture](../Save-For-Later-Design.md#caller-and-session-binding),
[usage source rules](../Save-For-Later-Design.md#sources-of-d),
[native qualification](../Save-For-Later-Design.md#native-qualification-gate),
and the [installed runner](../../tests/integration/README.md).

The native qualification ran only on Ubuntu 26.04 and without the product.
This engineering check runs the installed broker's real kiosk-rule pause step
on each target's GNOME, Malcontent and logind. Leave a child's graphical session
unlocked and switch away with a raw VT switch, then invoke PauseGrant with
kiosk rules. Require that the broker locks that session, observes LockedHint
and a completed usage record ending no earlier than one second before the lock
request, and captures D only after both. Require that the saved balance
excludes the switched-away interval. Check that a session that is already
locked needs no wait, and that a concurrent SSH session for the child does not
block the pause. Reuse 005's adapter seams for the lock-timeout and
missing-record refusals; do not repeat them here.

Add the planned engineering selector
`system --area session --test test_saved_time_lock_before_capture`
(unimplemented). Keep its fixtures and state assertions out of public customer
cases. Run affected host fixture checks and list the exact registered selector
before live use. Run it on every declared target and record the observed lock
and record latencies per target in normal runner output. A timing or ordering
mismatch is a platform mismatch to report under the design's qualification
gate, not an expectation to relax. Finish owned cleanup.
