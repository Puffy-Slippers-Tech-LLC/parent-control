# E09 — Generate and validate specific evidence links

Acceptance: host
Requires: E07a, E08

## Purpose and delivery

Implement exact link generation and semantic verification for the E01 document
consumer inventory under the [master](../Export-Execution-Plan.md) and
[reference design](../Export-Design.md#stable-and-specific-references). Read the
delivered identity/resolver/parser APIs, full plan reference collection/rewrite,
helper dispatch and all frozen queue/prose/brief/catalogue/handoff consumers.

Generate readable links selecting a verified exact record and its dependency
closure; prohibit new enduring references to disposable exports/reports. Validate
task/check/attempt/target/input/result and member digest, not just file existence.
Collect explicitly declared consumer references beyond queue Estimate cells.
Keep authored content and generated destinations separate. Return a finite preview
bound to original document bytes, requested context and exact proof before any
authorized rewrite. A verified generic locator without the selected member fails.
Preserve protected queue/claim/checkpoint boundaries and unrelated dirty work.
Register and document public validated interfaces before using them.

## Validation and close-out

Test wrong-but-existing report, old attempt with identical bytes, swapped targets,
different inputs, generic locator, absent original resolved by exact archive,
unsafe live source, changed document after preview and nested relative prose
links. Confirm every frozen consumer has coverage and no command executes from
link text. Use scoped host identity/document/launcher tests; update artifact and
execution-plan owners for delivered behavior and follow the master's close-out.
