# Track what can be paused without changing immediate approvals

Acceptance: host

Prerequisite is 002. Use the [balance model](../Save-For-Later-Design.md#state-and-time-arithmetic),
[grant modes](../Save-For-Later-Design.md#grant-modes),
[immediate approvals](../Save-For-Later-Design.md#immediate-approvals), and
[current grant arithmetic](../SystemDesign/Screen-Time.md#grant-arithmetic-and-usage-identities).

Implement the common second-based arithmetic and derived fixed/deadline mode.
Record qualifying immediate grants after the verified apply, and clear fixed
metadata for rest-of-day or a still-contributing deadline grant, preserving
saved time. Keep existing duration validation, usage identities, disabled
control behavior, midnight/DST resolution, and the old status and countdown
contracts. Leave new mutation wiring to later tasks.

Run focused grant/status/arithmetic regressions for D/A/S combinations, X on
both sides of D=A, pre-feature and external tuples, contributing deadline
grants, fractional request rounding, limits and timestamp bounds, expiry while
waiting for a parent, and failed apply or a crash before fixed tracking. Verify
that usable desktop time, countdown and login inputs still exclude saved time.
Run the queued package check and release owned fixtures and build allocations.
