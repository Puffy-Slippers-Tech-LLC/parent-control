# Pause from the child overlay and use the time from the kiosk

Acceptance: installed
Targets: onpc-Ubuntu26.04-101, onpc-Fedora44-201, onpc-Fedora45-301

Prerequisite is 017. Own the pause variant of
[Scenario 3](../Save-For-Later-Design.md#scenario-3-pause-save-and-use-time-from-the-child-overlay).
Use the [overlay lock confirmation](../Save-For-Later-Design.md#overlay-lock-confirmation)
and [E2E implementation route](../../tests/e2e/README.md#verify-edits).

Start in a signed-in child session with zero daily time and an
overlay-approved fixed grant. Open Approved time in the overlay, cancel the
lock confirmation once and require that the grant keeps running. Then confirm
Pause and lock, observe the native lock and the exhausted shield, and verify
the saved balance from the kiosk against the measured transfer interval. Use
saved time once at the kiosk, require the normal return to sign-in and password
unlock of the same session, and confirm the countdown reflects the redeemed
balance less the return/unlock interval. Keep each observation within the same
installed attempt.

Register the planned `saved-time-overlay-pause` variant in a new child-overlay
scenario family with an allocated coverage ID. Declare 024's
`saved-time-overlay-daily` variant pending until implemented. Record the
numeric selector in this brief before running. Run after preflight and
affected host checks on each declared target. Use separate host/engineering
checks for injected failures. Update recipe and coverage and finish owned
cleanup per target.
