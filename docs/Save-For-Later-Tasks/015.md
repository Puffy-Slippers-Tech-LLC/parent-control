# Check that removal preserves saved time only if it is aborted

Acceptance: installed
Targets: onpc-Ubuntu26.04-101, onpc-Fedora44-201, onpc-Fedora45-301

Prerequisite is 010. Use the [design lifecycle](../Save-For-Later-Design.md#app-policy-revocation-and-other-lifecycle-operations),
[package removal](../SystemDesign/Package-Removal.md#remove-purge-and-retry),
and [installed runner](../../tests/integration/README.md#installed-package-reboot-observation).

Extend the existing removal histories with an independently observed child
record containing saved time. Verify that abort restores the live tuple and
preserves the saved balance and recovery state, successful retry clears
entitlements at finalization, reinstall cannot resurrect them, and purge
removes the grant directory. Retain ordinary preferences until purge and
preserve unrelated account state. Keep engineering setup and state assertions
inside the existing guarded removal fixtures.

Run `system --id 6` on each target. On both Fedora targets use the existing
`system --area removal --test test_aborted_cleanup_rollback_retry` with its
native post-erase rollback and retry. Preserve the ordered lifecycle phases
and applicable platform-specific checks. Run the affected host fixture
checks and inventory listing before live execution. Collect actual results per
target and finish the installed runner's owned cleanup.
