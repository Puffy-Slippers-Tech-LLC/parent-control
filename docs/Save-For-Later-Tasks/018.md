[E2E implementation route](../../tests/e2e/README.md#verify-edits).

desktop. Use a three-minute initial grant and a one-minute custom deferred
request, with the timing budget agreed in the recipe before live execution.

exhausted retained-session shield, use saved time exactly once at the kiosk,
and verify normal return to sign-in and password unlock of the same desktop.
Verify the return/unlock interval consumes time, natural expiry restores the
restriction, and the saved balance cannot be used again.
