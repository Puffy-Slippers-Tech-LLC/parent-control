# Kiosk confinement proof

Test and design links refer to files in this repository. Recording numbers identify persistent test case IDs. Each case has one shared recording of the batch’s VM feeds; RPM-only case 8 runs on Fedora.

| Scenario ID | Offense Scenario | Confinement Defense |
| --- | --- | --- |
| 1 | At sign-in, select the request-station account but choose a normal desktop instead. | Dedicated-session routing is checked and repaired with denial of the current attempt; the final PAM boundary separately constrains the executable GDM actually starts. Proof: [system login admission](../tests/integration/system_kiosk_admission.py#L363) (<a href="https://youtu.be/duVHThWD3kY" target="_blank" rel="noopener noreferrer">Recording</a>) and [system final-exec matrix](../tests/integration/system_kiosk_confinement.py#L1984) (<a href="https://youtu.be/o3RAs4ijrzk" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 2 | Choose an older X11 session for the request station. | Saved transport must be Wayland, and session opening checks the PAM transport. The installed wrong-transport test proves account-stage denial, repair and successful fresh retry; it does not itself open an X11 session. Proof: [system admission matrix](../tests/integration/system_kiosk_admission.py#L363) (<a href="https://youtu.be/duVHThWD3kY" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 3 | Switch to a text console and try signing in as the request-station account. | The installed `login` PAM account gate denies the kiosk identity, backed by its nologin shell. An ordinary-account positive control prevents a broken PAM service counting as protection. Proof: [system admission matrix](../tests/integration/system_kiosk_admission.py#L348) (<a href="https://youtu.be/duVHThWD3kY" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 4 | Connect remotely by SSH and try using the request-station account. | The installed `sshd` account gate denies the kiosk; effective SSH configuration must use that PAM service. Proof: [system SSH configuration and admission assertions](../tests/integration/system_kiosk_admission.py#L363) (<a href="https://youtu.be/duVHThWD3kY" target="_blank" rel="noopener noreferrer">Recording</a>). This checks the installed gate, not a complete network SSH login. |
| 5 | Press Super to show the desktop overview, Super+A to show applications, or Ctrl+Alt+T to open a terminal. | The dedicated compositor exposes the request station without those desktop launch routes. Public checks require the form to remain usable and independently observe absence of forbidden windows after each input. Proof: [E2E cases 50–52](../tests/e2e/restricted_station.py) (<a href="https://youtu.be/PV2gM2Kyk8w" target="_blank" rel="noopener noreferrer">Recording</a>), [case implementation](../tests/e2e/restricted_station.py) (<a href="https://youtu.be/H7QXlXR3zZU" target="_blank" rel="noopener noreferrer">Recording 50</a>, <a href="https://youtu.be/mYsRRlX5UJo" target="_blank" rel="noopener noreferrer">Recording 51</a>, <a href="https://youtu.be/PV2gM2Kyk8w" target="_blank" rel="noopener noreferrer">Recording 52</a>). |
| 6 | <ul><li>Submit a request with a wrong administrator password.</li><li>After rejection, try the desktop and terminal shortcuts again.</li></ul> | Authentication denial grants no access and preserves the confined request form and choices. Restrictions are repeated after rejection. Proof: [E2E case 51](../tests/e2e/restricted_station.py#L60) (<a href="https://youtu.be/mYsRRlX5UJo" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 7 | <ul><li>Submit a request and cancel the administrator password prompt.</li><li>Try the desktop and terminal shortcuts again.</li></ul> | Password-free cancellation leaves the same confined form; the second restriction cycle still rejects all three routes. Proof: [E2E case 52](../tests/e2e/restricted_station.py#L92) (<a href="https://youtu.be/PV2gM2Kyk8w" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 8 | Cancel or close the request window to uncover a desktop behind it. | Normal request exit ends the station surface and returns to usable sign-in, without exposing a station desktop. Proof: [E2E Cancel case 47](../tests/e2e/kiosk_cancel.py) (<a href="https://youtu.be/kUD27lB7hQk" target="_blank" rel="noopener noreferrer">Recording</a>), [surface-close case 48](../tests/e2e/kiosk_escape.py) (<a href="https://youtu.be/JPvGgxhZCr4" target="_blank" rel="noopener noreferrer">Recording</a>). Case 48 uses the guarded close operation, not proof of every native close gesture. |
| 9 | After a parent approves more time, stay in the station and use it as an unrestricted account. | Approval updates the selected child's authorization and the restricted-station success route exits to sign-in. It does not remove kiosk MAC policy or grant administration. Proof: [E2E case 50](../tests/e2e/restricted_station.py#L33) (<a href="https://youtu.be/H7QXlXR3zZU" target="_blank" rel="noopener noreferrer">Recording</a>), [broker authorization](SystemDesign/Broker.md#authorization-and-grant-transactions). |
| 10 | Open About or Help and look for a website, file browser or management window to launch. | Kiosk About keeps information in-app and excludes external-handler, chooser and management actions; closing it preserves the unfinished request. Proof: [E2E case 192](../tests/e2e/kiosk_about.py) (<a href="https://youtu.be/IhYLNWyBj88" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 11 | <ul><li>Open Preferences.</li><li>Visit Language, Reminders and Preset Times.</li><li>Open the Add/Edit dialogs and look for a way to launch another app or browse files.</li></ul> | The exposed controls are checked for unexpected surfaces, external links and forbidden actions. Cancelling drafts returns to the unchanged request, followed by a strict confined-process census. Proof: [installed Preferences qualifier](../tests/integration/check_e2e_kiosk_preferences_confinement.py), [journey assertions](../tests/e2e/kiosk_preferences_confinement.py). |
| 12 | Open an error report, edit its text, or open the privacy disclosure to reach files or another app. | Reporting remains in-app; kiosk chooser/external-handler actions are suppressed. The qualifier proves usable editing, privacy navigation and a waiting-session census without submitting a report. Proof: [installed feedback qualifier](../tests/integration/check_e2e_kiosk_feedback_confinement.py), [journey assertions](../tests/e2e/kiosk_feedback_confinement.py). |
| 13 | Ask a background service to open a shell or run a Python/GJS command, desktop shell or alternate session. | The user manager and service executors retain role-specific MAC restrictions. Each prohibited command requires an executor failure and fresh matching kernel denial after successful native execution. Proof: [system execution matrix](../tests/integration/system_kiosk_confinement.py#L1984) (<a href="https://youtu.be/o3RAs4ijrzk" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 14 | Copy an allowed program into a writable folder, rename it, or make a shortcut to an interpreter and run it. | Execution authority depends on trusted private paths/inodes and role transitions, not matching file contents or a friendly name. A copied executable and interpreter symlink are explicitly denied. Proof: [system writable-input assertions](../tests/integration/system_kiosk_confinement.py#L1414) (<a href="https://youtu.be/o3RAs4ijrzk" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 15 | Run a program through its library loader, an already-open file, or a program held only in memory. | The final GDM execution gate denies explicit loader invocation, file-descriptor execution and memfd execution with native permission errors. An allowed actual final exec precedes those negatives. Proof: [system final-exec matrix](../tests/integration/system_kiosk_confinement.py#L1984) (<a href="https://youtu.be/o3RAs4ijrzk" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 16 | Create a background startup job and mark its command as privileged to bypass restrictions. | A user unit's `ExecStart=+` does not remove the manager's MAC boundary or turn the kiosk into root. The test verifies the exact writable unit and effective prefix before requiring the shell execution denial. Proof: [system user-unit assertions](../tests/integration/system_kiosk_confinement.py#L1414) (<a href="https://youtu.be/o3RAs4ijrzk" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 17 | Ask the background service manager to run a job without its security profile, including “ignore errors.” | Unconfined profile/context selection is denied; ignoring that setup error still leaves forbidden shell execution blocked by the kernel. Proof: [system service-API assertions](../tests/integration/system_kiosk_platform.py#L340) (<a href="https://youtu.be/BcWyfcbeS_Y" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 18 | Put custom startup settings or scripts in a writable folder so notifications, audio or Wellbeing will run them. | Fixed launchers reject extra arguments and clear startup injection. Audio uses system roots and empty default Lua paths. Proof: [system hostile-startup and Lua assertions](../tests/integration/system_kiosk_platform.py#L186) (<a href="https://youtu.be/BcWyfcbeS_Y" target="_blank" rel="noopener noreferrer">Recording</a>), [fixed launcher implementation](../tools/kiosk_session.c). Qualification covers the reviewed native inputs, not every optional plugin. |
| 19 | Ask the audio service to load a custom plugin from a writable folder. | Kernel executable-mapping policy rejects the user-owned ELF even when requested through the real native metadata API. A genuine trusted-library load is observed first. Proof: [system native audio API assertions](../tests/integration/system_kiosk_platform.py#L285) (<a href="https://youtu.be/BcWyfcbeS_Y" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 20 | Use the report editor's web or media helpers to substitute a program or load writable code. | Separate bootstrap/payload roles, pinned native proxy/scanner paths and read-only executable binds prevent tested substitutions. Six bind/data/file attacks require an independent native positive and enforcing denial. Proof: [system bubblewrap substitution assertions](../tests/integration/system_kiosk_confinement.py#L1245) (<a href="https://youtu.be/o3RAs4ijrzk" target="_blank" rel="noopener noreferrer">Recording</a>), [installed feedback qualifier](../tests/e2e/kiosk_feedback_confinement.py). |
| 21 | Use an image decoder or a sandbox helper as a way to launch another program or change the system's mounts. | Glycin has a finite pinned decoder route with no onward exec; only native bootstrap roles have bounded private-namespace setup authority. Proof: [role policy](../tools/kiosk_confinement_policy.py) and [bubblewrap assertions](../tests/integration/system_kiosk_confinement.py#L1245) (<a href="https://youtu.be/o3RAs4ijrzk" target="_blank" rel="noopener noreferrer">Recording</a>). These checks do not establish immunity to unknown decoder vulnerabilities. |
| 22 | Use the administrator password helper as a general privileged program launcher. | Only the pinned vendor authentication helper and its finite transitions are permitted; native binding checks privilege metadata before and after mounting. Fedora's helper census requires exact credentials, label, parent, namespace and generation. Proof: [system helper identity assertions](../tests/integration/system_kiosk_confinement.py#L197) (<a href="https://youtu.be/o3RAs4ijrzk" target="_blank" rel="noopener noreferrer">Recording</a>), [public authentication in cases 50–52](../tests/e2e/restricted_station.py) (<a href="https://youtu.be/PV2gM2Kyk8w" target="_blank" rel="noopener noreferrer">Recording</a>). |
| 23 | Change the request station's default desktop or ask it to manage parental-control settings. | Root-owned routing and Polkit protect the account metadata; the kiosk has no management UI route. Broker methods independently check caller roles, targets and approval. Proof: [system routing denial/recovery](../tests/integration/system_kiosk_admission.py#L363) (<a href="https://youtu.be/duVHThWD3kY" target="_blank" rel="noopener noreferrer">Recording</a>), [system
