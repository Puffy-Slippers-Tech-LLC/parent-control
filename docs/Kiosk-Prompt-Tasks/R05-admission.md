# R05 — Remove broad admission dependencies

Acceptance: host

Requires R04. Read the [master](../Kiosk-Resilience-Plan.md#target-design), R01's
decision ledger and both early-proof receipts. Read full native fresh/retained
callers, preparation/material/policy owners and packaging activation paths
affected by the chosen replacement.

## Deliverable

Integrate the proven minimal boundary into ordinary production entry. Remove
ambient host enumeration and exact cosmetic-resource identity from admission.
Remove retained-manager filesystem reconstruction and generation matching that
the accepted design made unnecessary. Keep code-loading, authorization and
attacker-writable consumed-input protection at their actual authorities.

Complete the intended consumers/search paths and preparation/activation interface;
unrecognized benign host content must be irrelevant to entry. Replace duplicated
checks only when their single owning boundary provides the concrete protection.
Do not retain a hidden compatibility fallback to the old broad gate.

Delete superseded production paths, protocol/state fields and tests of their
obsolete implementation guarantees in this change. Preserve or port behavioral
escape, privilege, ordinary-account and cleanup controls according to R01's
explicit mapping. Keep the shared child-overlay behavior unchanged unless a
specified shared correction is necessary.

## Validation and close-out

Run affected entry/PAM/material/session/package regressions at host scope,
including unknown-layout and cosmetic-change positive controls and concrete
escape negatives through actual callers. Confirm omitted resources cannot be
reclassified as essential by another layer. Review changed resource ownership
and retention through existing contracts.

Require the master's product review and `make build` after the final packaged
edit. Update current implementation details and ledger; record exact input
changes for final installed acceptance. Finish owned cleanup. Session exception:
one shared native entry replacement and its necessary callers stay together.
